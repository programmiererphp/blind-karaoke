# Design Assets

These files are the current **light concept/mockup graphics** for Blind Karaoke. They are repository-native SVG references that can be opened directly in GitHub or supplied to an implementation agent.

Mockups containing visible `wfwebapp` branding were intentionally excluded because `wfwebapp` is only the creation-workflow name.

1. `01-master-flow.svg` — primary full user-flow reference; accepted source direction GenID `39051671-d178-4a15-ab4b-81e526020a03`.
2. `02-flow-light-mobile.svg` — alternate light mobile flow.
3. `03-detail-preferences-match.svg` — preference and blind-match details.
4. `04-detail-room-after.svg` — Karaoke Room and post-session details.
5. `05-product-flow-reference.svg` — wider product/desktop reference.

Written requirements override visual details if there is any conflict.

## Runtime screenshots

`screenshots/` is reserved for screenshots of the **real deployed app**. Those should only be added after Delivery 1 is implemented and browser-tested.
