# Design Assets

These files are the current **light concept mockups** for Blind Karaoke. They are design references, not screenshots of an already-running deployment.

Mockups containing visible `wfwebapp` branding were intentionally excluded because `wfwebapp` is only the creation-workflow name.

1. `01-master-flow.webp` — primary accepted product-flow reference; original GenID `39051671-d178-4a15-ab4b-81e526020a03`.
2. `02-flow-light-mobile.webp` — alternate light multi-screen flow.
3. `03-detail-preferences-match.webp` — preference/match-oriented reference.
4. `04-detail-room-after.webp` — room and post-meeting flow reference.
5. `05-product-flow-reference.webp` — wider product concept/reference.

Written requirements override visual details if there is any conflict.

Actual screenshots of the deployed webapp should be added here only after Delivery 1 is implemented and browser-tested.
