# Design Reference

## Direction
- white background
- very light gray section surfaces
- dark navy/black readable text
- pink primary CTA
- restrained violet secondary accent
- soft shadows
- rounded cards
- generous whitespace
- mobile-first
- no dark disco theme
- no persistent neon look
- no esoteric visual language
